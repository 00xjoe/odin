✨ Features
🎟️ Dynamic Movie Selection — Choose from multiple movies with different ticket prices

💺 Interactive Seats — Click to select/deselect your perfect spot

💰 Real-time Pricing — Watch the total update instantly as you pick seats

🎨 Visual Seat Legend — Color-coded indicators for:

🟩 Available

🟦 Selected

🟥 Occupied

🧹 One-Click Reset — Clear all selections with a single button

🖥️ Cinema Screen UI — Immersive theater layout with curved screen display

🛠️ Tech Stack
Technology	Purpose
HTML5	Structure & layout
CSS3	Styling & animations
Vanilla JS	Interactive logic & local storage
💡 No frameworks, no dependencies — pure vanilla goodness!

🎮 How to Use
Pick a movie from the dropdown menu

Click available seats (green) to select them

Watch the counter — seats and price update live

Enjoy the show! 🍿
