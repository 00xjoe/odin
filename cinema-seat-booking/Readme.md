# 🎬 Cinema Seat Booking App

A simple and interactive web application for booking cinema seats. Users can select a movie, choose available seats, and see the total price update in real-time.

---

## 🚀 Features

- 🎟 Select from multiple movies with different ticket prices
- 💺 Interactive seat selection system
- 📊 Live update of selected seats and total cost
- 🟥 Visual legend for seat states (Available / Selected / Occupied)
- 🧹 Clear selection button
- 🎬 Cinema screen layout UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
