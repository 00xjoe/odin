A warm and inviting restaurant website for **The Cozy Spoon**, built with pure HTML and CSS. The site showcases the restaurant's menu, daily specials, and includes an order form for customers.

---

##  Project Overview

This is part of [The Odin Project](https://www.theodinproject.com/) front-end curriculum. The project demonstrates:

- Semantic HTML5 structure
- CSS styling and layout
- Multi-page navigation
- Form handling (order placement)
- Responsive design principles

---

---

##  Features

### Main Page (`restaurant.html`)
- **Header** with restaurant name and branding
- **Navigation bar** linking to menu section, order form, and specials page
- **Menu Section** displaying:
  - Pasta Primavera - $12.99
  - Grilled Chicken Sandwich - $10.99
  - Chocolate Lava Cake - $6.50
- **Order Form** with:
  - Quantity inputs for each menu item
  - Add-ons & sides (fries, salad) with checkboxes
  - Drink selection via radio buttons (water, soda, coffee)
  - Special requests text area
  - Submit button

### Today's Specials Page (`today-food.html`)
- Daily rotating specials:
  - Creamy Mushroom Soup - $7.99
  - Beef Burger Deluxe - $11.50
  - Strawberry Cheesecake - $6.99
- Navigation back to main page

##  How to Run

1. Clone or download this repository
2. Open `restaurant.html` in any modern web browser
3. Navigate between pages using the nav links
