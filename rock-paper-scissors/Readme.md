# Rock Paper Scissors

A classic Rock Paper Scissors game built with HTML, CSS, and JavaScript. Challenge the computer in a best-of-5 showdown!

## Features

- Player vs Computer gameplay with random computer choices
- First to 5 wins format for exciting matches
- Real-time score tracking for both players
- Visual feedback with hover effects and button animations
- Game-over detection with play-again functionality
- Responsive design that works on different screen sizes
- Clean, modern UI with gradient background and styled buttons

## How to Play

1. Open `index.html` in your web browser
2. Click Rock, Paper, or Scissors to make your move
3. The computer will randomly select its move
4. First player to reach 5 points wins the game
5. Choose to play again when the match ends

### Game Rules
- Rock crushes Scissors
- Paper covers Rock
- Scissors cuts Paper
