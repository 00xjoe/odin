## 🗂️ Projects

### 🎬 [Cinema Seat Booking App](./cinema-seat-booking/)
*An interactive movie ticket booking experience*

- **Concepts Applied:** DOM manipulation, event delegation, local state management, dynamic UI updates
- **Key Features:**
  - Movie selection with variable pricing
  - Interactive seat picker with visual feedback
  - Real-time price calculation
  - Color-coded seat states (Available/Selected/Occupied)
- **Skills Demonstrated:** Array manipulation, event handling, CSS layout design, user experience consideration

---

### ✊ [Rock Paper Scissors](./rock-paper-scissors/)
*A classic game implementation with computer AI*

- **Concepts Applied:** Conditional logic, random generation, game state management, score tracking
- **Key Features:**
  - Player vs Computer gameplay
  - First-to-5 win condition
  - Visual feedback on game outcomes
  - Play-again functionality
- **Skills Demonstrated:** Control flow, function organization, UI feedback systems, game logic design
